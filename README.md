# Pit Stop Cohab — Estoque de Produtos para Festas

Versão de teste **sem Firebase** e **sem login**.

Os dados ficam salvos no navegador usando `localStorage`, ideal para validar o layout e as funções antes de ativar nuvem.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra o endereço informado pelo Vite.

## Build

```bash
npm run build
npm run preview
```

## GitHub

Pode enviar todos os arquivos deste projeto ao GitHub. A pasta `node_modules` não deve ser enviada.

## Nesta versão

- Dashboard preto/dourado Pit Stop Cohab
- Cadastro de produtos
- Quantidade e estoque mínimo
- Preço do fornecedor
- Preço de venda
- Preços de concorrentes já suportados no modelo
- Valor do estoque e lucro potencial
- Pit IA local baseada nos dados cadastrados
- Persistência local sem serviços externos
